## 🚀 Quick Start (5 Menit)

### Step 1: Setup Company Info
```
Admin → Settings → Informasi Perusahaan
Isi: Nama, Alamat, Phone, Email, Logo
Klik: Simpan
```

### Step 2: Catat Pembayaran Pertama
```
Admin → Finance → Pilih Booking
Klik: Icon History (ungu)
Tambah: Pembayaran Baru
```

### Step 3: Generate Invoice
```
Admin → Finance → Pilih Booking
Klik: Invoice
Download: PDF
```

### Step 4: Export Laporan
```
Admin → Finance
Filter: Pilih Periode
Klik: Export CSV
```

✅ **Done!** Anda siap menggunakan semua fitur baru.

## 🐛 Troubleshooting

### Problem: PDF tidak download
**Solution:**
1. Disable popup blocker
2. Coba browser lain (Chrome recommended)
3. Clear cache & refresh

### Problem: Data tidak muncul
**Solution:**
1. Refresh page (F5)
2. Cek filter tanggal
3. Logout & login lagi

### Problem: Logo tidak muncul di invoice
**Solution:**
1. Upload ulang logo (PNG format)
2. Pastikan URL valid
3. Klik Simpan di Settings

### Problem: Export CSV error
**Solution:**
1. Cek koneksi internet
2. Coba filter lebih spesifik
3. Refresh page
