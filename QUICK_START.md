## 💰 Catat Pembayaran (2 Menit)

### Skenario: Klien bayar DP Rp 1.000.000

```
1. Buka tab "Finance" (Keuangan)
2. Cari nama klien
3. Klik icon History (ungu) 🕐
4. Klik "Tambah Pembayaran Baru"
5. Isi:
   - Jumlah: 1000000 (otomatis jadi Rp 1.000.000)
   - Metode: Transfer Bank
   - Tanggal: Hari ini
   - ✅ Verified
6. Klik "Simpan"
```

✅ **Done!** Pembayaran tercatat, status berubah otomatis.

---

## 🧾 Generate Invoice (1 Menit)

### Kirim invoice ke klien

```
1. Buka tab "Finance"
2. Cari booking klien
3. Klik tombol "Invoice" 📄
4. Review invoice di tab baru
5. Klik "Download PDF" 📥
6. Kirim PDF ke klien via WhatsApp
```

✅ **Done!** Klien terima invoice profesional.

---

## 📊 Export Laporan Bulanan (30 Detik)

### Laporan Mei 2026

```
1. Buka tab "Finance"
2. Klik "Custom" di filter Periode
3. Dari: 01/05/2026
4. Sampai: 31/05/2026
5. Klik "Export CSV" 📊
```

✅ **Done!** Laporan siap untuk akuntan.

## 🔥 Pro Tips

### 1. Catat Pembayaran Real-time
❌ **Jangan:** Tunggu akhir bulan baru catat semua
✅ **Lakukan:** Catat segera setelah terima transfer

### 2. Backup Rutin
❌ **Jangan:** Hanya andalkan database
✅ **Lakukan:** Export CSV setiap akhir bulan

## 🐛 Troubleshooting Cepat

### PDF tidak download?
```
1. Disable popup blocker
2. Coba browser lain (Chrome)
3. Refresh page (F5)
```

### Data tidak muncul?
```
1. Refresh page (F5)
2. Cek filter tanggal
3. Logout & login lagi
```

### Logo tidak muncul di invoice?
```
1. Buka Settings
2. Upload ulang logo (PNG format)
3. Klik Simpan
4. Generate invoice lagi
```
